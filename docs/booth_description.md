## 商品説明文

### 概要

理系大学生向けのノート設計・PDF出力アプリのFlutterソースコードです。  
方眼・罫線・コーネルノートなど多彩なレイヤーをカスタマイズして組み合わせ、自分だけのノートをPDFで出力できます。

---

### 主な機能

**レイヤー種類（18種）**
- 方眼 / ドット / 罫線 / コーネルノート
- 対数グラフ（片対数・両対数）/ 極座標グラフ
- 数式罫線（上付き・下付きゾーン対応）
- 表 / 座標軸 / ヘッダー欄
- 原稿用紙 / 週間タイムテーブル
- カスタム線 / ガイド / 領域分割

**スタンプ機能**
- 化学・物理・数学・汎用の図形を自由配置
- 回転・色変更・サイズ調整対応

**PDF出力**
- 複数ページ一括出力
- 穴あきマーク（26穴・30穴）対応
- 行番号・ページ番号の自動挿入

**テンプレートギャラリー**
- Firestoreを使ったテンプレート共有
- いいね・コメント・フォロー機能

**その他**
- Undo / Redo（最大50件）
- レイヤードラッグ移動・ピンチリサイズ
- サブスクリプション（RevenueCat連携）
- A4 / B5 / A3 / B4 / Letter 対応・縦横両対応

---

### 技術スタック

| 分類 | 使用技術 |
|---|---|
| フレームワーク | Flutter 3.x / Dart |
| 状態管理 | Riverpod (riverpod_annotation) + freezed |
| ローカルDB | Drift |
| バックエンド | Firebase (Auth / Firestore / Storage) |
| サブスク管理 | RevenueCat |
| PDF生成 | dart-pdf |
| ルーティング | go_router |

---
